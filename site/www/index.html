Receber suporte

Atendimento remoto da Jrtech no seu computador

Baixe o JrTechDesk Suporte e passe ao técnico o ID e a senha que aparecem na tela. O programa abre direto, sem instalar.

Baixar para Windows x64 · .exe · Windows 10 e 11

Outros sistemas: Windows | Linux

Está no celular? Este programa é para computador. No computador, abra o navegador e digite baixar.desbloqueiorepidclass.com.br

Como funciona

  1. Baixe. Clique em Baixar para Windows.
  2. Abra o arquivo JrTechDesk-suporte.exe. Ele aparece no canto de cima do navegador ou na pasta Downloads (Ctrl + J).
  3. Diga ao técnico o ID e a senha. Quando ele pedir, clique em Aceitar. Para terminar, feche o programa.

Segurança

Passe o ID e a senha só para o técnico da Jrtech que está atendendo você. Se alguém ligar dizendo ser da Jrtech sem você ter pedido atendimento, desligue e procure o suporte da Jrtech.

Apareceu um aviso?

Se o navegador ou o Windows disser que o arquivo pode ser perigoso, que não é baixado com frequência ou que “o Windows protegeu o computador”, não continue sozinho. Avise o técnico que está atendendo você ou procure o suporte da Jrtech.

Não achou o arquivo?

Aperte Ctrl + J e abra o arquivo que você acabou de baixar desta página. O nome pode terminar em (1).exe.

Dar suporte

Para técnicos da Jrtech

O Completo acessa outras máquinas. O Suporte só recebe conexões. Todos os pacotes são para 64 bits (x86-64).

Windows

Windows 10 ou 11, 64 bits

  • Completo JrTechDesk-completo.exe
  • Suporte JrTechDesk-suporte.exe

Ubuntu e Debian

Ubuntu 22.04 ou mais novo, e derivados

  • Completo jrtechdesk-completo.deb 
    sudo apt install ~/Downloads/jrtechdesk-completo.deb
  • Suporte jrtechdesk-suporte.deb 
    sudo apt install ~/Downloads/jrtechdesk-suporte.deb

Arch Linux

Arch atualizado e derivados

  • Completo jrtechdesk-completo.pkg.tar.zst 
    sudo pacman -U ~/Downloads/jrtechdesk-completo.pkg.tar.zst
  • Suporte jrtechdesk-suporte.pkg.tar.zst 
    sudo pacman -U ~/Downloads/jrtechdesk-suporte.pkg.tar.zst

Conferir os arquivos

Antes de instalar, baixe o SHA256SUMS.txt para a mesma pasta dos pacotes e rode o comando. Confira se aparece OK ao lado do pacote que você vai instalar. Se o navegador acrescentou “(1)” ao nome porque já havia uma cópia antiga, apague as cópias antigas e baixe de novo.

cd ~/Downloads && LC_ALL=C sha256sum -c --ignore-missing SHA256SUMS.txt

O programa avisa quando há versão nova. No Windows, clique em Atualizar no aviso (ou em Baixar, quando for essa a opção). No Linux, baixe e instale o pacote novo.

Privacidade

  • Esta página não usa cookies, não tem rastreamento, anúncios nem formulários e não carrega nada de outros sites.
  • Durante o atendimento, o técnico vê a sua tela e pode controlar o computador, inclusive abrir e transferir arquivos, para resolver o que você pediu. O acesso só começa quando você passa o ID e a senha e aceita a conexão, e termina quando você fecha o programa.
  • A conexão é criptografada e usa os servidores da própria Jrtech, sem serviços de terceiros.
  • Dúvidas sobre os seus dados pessoais: fale com o técnico que atendeu você ou procure o suporte da Jrtech.

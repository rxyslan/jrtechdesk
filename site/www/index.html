§01 · Cliente

Suporte remoto da Jrtech

Programa para o técnico da Jrtech acessar o seu computador durante o atendimento. Abre direto, sem instalar.

Baixar JrTechDesk Suporte Windows 10 e 11 · 64 bits

Arquivo JrTechDesk-suporte.exe

Está no celular? Este programa é para computador com Windows. No computador, abra o navegador e digite baixar.desbloqueiorepidclass.com.br

Passo a passo

  1. Baixe. Clique em Baixar JrTechDesk Suporte.
  2. Abra o arquivo JrTechDesk-suporte.exe. Ele aparece no canto de cima do navegador. Se não aparecer, aperte Ctrl + J ou abra a pasta Downloads. Se aparecer um aviso do navegador ou do Windows, não continue: avise o técnico ou procure o suporte da Jrtech (mais detalhes).
  3. Diga ao técnico o ID e a senha. Eles aparecem na tela do programa. Quando ele pedir, clique em Aceitar. Para terminar o atendimento, feche o programa.

Segurança. Passe o ID e a senha só para o técnico da Jrtech que está atendendo você. Se alguém ligar dizendo ser da Jrtech sem você ter pedido atendimento, desligue e procure o suporte da Jrtech.

Não encontrei o arquivo ou apareceu um aviso
  • Aperte Ctrl + J e abra o arquivo que você acabou de baixar desta página. O nome pode terminar em (1).exe.
  • Apareceu um aviso do navegador ou do Windows dizendo que o arquivo pode ser perigoso, que não é baixado com frequência ou que “o Windows protegeu o computador”? Não continue sozinho. Avise o técnico que está atendendo você ou procure o suporte da Jrtech.
  • O programa funciona no Windows 10 e 11 de 64 bits.

§02 · Técnicos

Para técnicos

O Completo acessa outras máquinas; o Suporte só recebe conexões. Todos os pacotes são para 64 bits (x86-64). Os comandos supõem os arquivos em ~/Downloads com o nome original. Se o navegador acrescentou “(1)” ao nome porque já havia uma cópia antiga, apague as cópias antigas e baixe de novo, para conferir e instalar o mesmo arquivo.

Windows 10 e 11

  • Completo acessa outras máquinas JrTechDesk-completo.exe
  • Suporte abre direto, sem instalar JrTechDesk-suporte.exe

Ubuntu, Debian e derivados

  • Completo acessa outras máquinas jrtechdesk-completo.deb 
    sudo apt install ~/Downloads/jrtechdesk-completo.deb
  • Suporte só recebe conexões jrtechdesk-suporte.deb 
    sudo apt install ~/Downloads/jrtechdesk-suporte.deb

Arch Linux e derivados

  • Completo acessa outras máquinas jrtechdesk-completo.pkg.tar.zst 
    sudo pacman -U ~/Downloads/jrtechdesk-completo.pkg.tar.zst
  • Suporte só recebe conexões jrtechdesk-suporte.pkg.tar.zst 
    sudo pacman -U ~/Downloads/jrtechdesk-suporte.pkg.tar.zst

Conferir os arquivos

Antes de instalar, baixe o SHA256SUMS.txt para a mesma pasta dos pacotes e rode o comando abaixo. Confira se aparece OK ao lado do nome do pacote que você vai instalar.

cd ~/Downloads && LC_ALL=C sha256sum -c --ignore-missing SHA256SUMS.txt

O programa avisa quando há versão nova. No Windows, clique em Atualizar no aviso (ou em Baixar, quando for essa a opção); no Linux, baixe e instale o pacote novo.

Suporte remoto da Jrtech

Baixe o programa, abra e passe o ID e a senha que aparecerem para o técnico. Não precisa instalar.

Baixar JrTechDesk Suporte Windows · cerca de 25 MB

  1. 1
    Baixe o arquivo pelo botão acima.
  2. 2
    Abra o arquivo baixado. Se o Windows mostrar “O Windows protegeu o computador”, clique em Mais informações e depois em Executar assim mesmo.
  3. 3
    Informe o ID e a senha ao técnico e aceite a conexão. Para encerrar o atendimento, basta fechar o programa.

Para técnicos

O Completo é instalado no computador e serve para acessar outras máquinas. O Suporte só recebe conexões e roda sem instalar.

SistemaCompletoSuporte
Windows 10 e 11 JrTechDesk-completo.exe JrTechDesk-suporte.exe
Ubuntu, Debian e derivados jrtechdesk-completo.deb jrtechdesk-suporte.deb
Arch Linux e derivados .pkg.tar.zst .pkg.tar.zst
  • Linux: sudo apt install ./jrtechdesk-completo.deb ou sudo pacman -U jrtechdesk-completo.pkg.tar.zst.
  • O programa avisa quando há versão nova; ninguém precisa voltar aqui para atualizar.
  • Para conferir os arquivos: SHA256SUMS.txt.
